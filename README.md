# 가정 내 자본주의

아이 용돈·집안일을 포인트로 기록하는 가족용 앱입니다. 부모 폰과 아들 폰이 서버(Supabase)를 통해 같은 장부를 봅니다. 안드로이드 앱(APK)으로 설치해서 씁니다.

## 설치하기 (APK)

1. 이 저장소의 **Releases** 에서 가장 위의 `childcare-vNN.apk` 를 폰에서 내려받습니다. (서명 키를 아직 등록하지 않았다면 **Actions → 최신 실행 → Artifacts** 의 `childcare-apk-NN`)
2. 파일을 열면 "출처를 알 수 없는 앱" 허용 안내가 나옵니다. **설정 → 이 출처 허용** 후 설치하세요.
3. 앱을 열고, **부모 폰**은 "우리 집 새로 시작하기"로 가족을 만든 뒤 **설정 → 기기 연결 → 아들 폰 코드**를 누릅니다. **아들 폰**은 앱을 열어 그 8글자 코드를 입력합니다. (코드는 30분 안에 한 번만 쓸 수 있어요.)

## 업데이트 (덮어쓰기)

새 APK 를 내려받아 그대로 설치하면 데이터(연결 정보)가 유지된 채 업데이트됩니다. **같은 서명 키**로 만든 APK 끼리만 덮어쓰기가 되므로, 아래 *Secrets 등록*을 꼭 먼저 하세요.

## 처음 한 번만: 서명 키(Secrets) 등록

서명 키가 없으면 빌드마다 다른 임시 키로 서명돼서 업데이트가 안 됩니다.

1. 컴퓨터(JDK 설치됨)에서 `bash scripts/gen-keystore.sh` 를 실행합니다. 키 파일(`childcare.jks`)은 저장소 **밖**에 만들어지고, 아래 4개 값이 출력됩니다. **키 파일은 안전한 곳에 백업**하세요. 잃어버리면 업데이트가 안 됩니다.
2. GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret** 에서 이름 그대로 4개를 등록합니다.
   - `ANDROID_KEYSTORE_BASE64`
   - `ANDROID_KEYSTORE_PASSWORD`
   - `ANDROID_KEY_ALIAS`
   - `ANDROID_KEY_PASSWORD`
3. **Actions → APK 빌드 → Run workflow** 를 누르면 서명된 APK 가 만들어져 Releases 에 올라옵니다.

> 이 저장소는 공개입니다. 키·비밀번호는 **절대 커밋하지 마세요**(`*.jks` 는 `.gitignore` 처리됨). 앱 안에는 Supabase 주소와 공개용 키만 들어 있고, 데이터 접근은 기기마다 발급되는 열쇠(서버에는 해시만 저장)로 보호됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 설치가 "앱이 설치되지 않음" | 이전에 다른 서명으로 설치한 앱이 있으면 지우고 다시 설치(연결 코드를 다시 받아야 해요). 이후엔 같은 키라 덮어쓰기됩니다. |
| 아들 화면이 안 바뀜 | 화면 위 주황 띠가 보이면 인터넷이 끊긴 것입니다. 연결되면 눌러 둔 동작이 자동으로 전송돼요. |
| "이 기기의 연결이 해제됐어요" | 부모 앱 설정에서 기기를 해제했거나 앱 데이터를 지웠을 때입니다. 새 연결 코드로 다시 연결하세요. |
| PIN 을 잊음 | 잠금 화면의 "PIN을 잊었어요"로 연결을 해제한 뒤, **복구 코드**를 연결 입력칸에 붙여 넣어 부모 기기로 다시 연결합니다. 복구 코드는 미리 부모 앱 설정에서 확인해 적어 두세요. |
| 빌드가 실패 | Actions 의 실행 로그를 확인하세요. Secrets 가 없으면 디버그 APK 만 만들어지는 것이 정상입니다. |

## 개발

```bash
npm install
npm test               # SQL(로컬 PostgreSQL 16) + 단위 + 브라우저 E2E (Playwright/Chromium)
npm run android:sync   # www/ 를 android/ 로 복사 (CI 가 자동으로 함)
npm run check:android  # 안드로이드 셸 점검
```

- `www/` — 앱 본체(번들러 없는 ES 모듈). 서버 상태가 진실이고, 눌러 둔 동작은 순서 있는 큐로 보냅니다.
- `supabase.sql` — 서버 스키마와 함수(Supabase SQL Editor 에서 실행).
- `docs/superpowers/` — 설계 문서와 구현 계획.
