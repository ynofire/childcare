# 가정 내 자본주의

아이 용돈·집안일을 포인트로 기록하는 가족용 앱입니다. 부모 폰과 아들 폰이 서버(Supabase)를 통해 같은 장부를 봅니다. 안드로이드 앱(APK)으로 설치해서 씁니다.

## 설치하기 (APK)

1. 이 저장소의 **Releases** 에서 가장 위의 `childcare-vNN.apk` 를 폰에서 내려받습니다. 반드시 이 저장소의 Releases 에서만 받으세요.
2. 파일을 열면 "출처를 알 수 없는 앱" 허용 안내가 나옵니다. **설정 → 이 출처 허용** 후 설치하세요.
3. 앱을 열고, **부모 폰**은 "우리 집 새로 시작하기"로 가족을 만든 뒤 **설정 → 기기 연결 → 아들 폰 코드**를 누릅니다. **아들 폰**은 앱을 열어 그 8글자 코드를 입력합니다. (코드는 30분 안에 한 번만 쓸 수 있어요.)

## 쓰는 방법 (승인제)

- 아들이 하는 모든 것(앞가림, 패드 사용, 심부름, 미션, 포인트 쓰기)은 **신청**이고, 부모가 **승인**해야 잔고에 반영됩니다. 거절하면 아무 변화가 없고 아들은 다시 신청할 수 있어요.
- 앞가림·패드는 하루 한 번, **심부름(강아지 케어 포함)과 포인트 쓰기는 하루 여러 번** 신청할 수 있어요. 승인 대기는 항목당 5건까지입니다.
- 포인트 쓰기는 승인 대기 중인 것까지 합쳐서 잔고가 모자라면 신청할 수 없어요. 승인할 때도 잔고가 모자라면 승인되지 않습니다.

## 업데이트 (덮어쓰기)

새 APK 를 내려받아 그대로 설치하면 데이터(연결 정보)가 유지된 채 업데이트됩니다. 앱을 열면 새 버전이 있을 때 화면 위에 **새 버전이 있어요 · 받기** 띠가 떠요(설치는 직접 눌러야 해요). `main` 에 앱 코드가 올라갈 때마다 GitHub Actions 가 자동으로 빌드해서 Releases 에 올립니다. (수동 실행: **Actions → APK 빌드 → Run workflow**)

## 서명 키에 대해 (공개 키)

가족용 앱이라 **시크릿 등록 없이** 빌드되도록, 서명 키(`android/app/childcare-public.jks`)를 저장소에 일부러 포함했습니다. 같은 키로 서명되므로 업데이트는 항상 덮어쓰기가 됩니다.

- 단점: 키가 공개라서, 누구나 이 키로 서명한 가짜 APK 를 만들 수 있습니다. **이 저장소 Releases 에서 받은 APK 만 설치**하세요.
- 가족 데이터는 앱의 서명이 아니라 기기마다 발급되는 열쇠(서버에는 해시만 저장)로 보호됩니다. 앱 안에는 Supabase 주소와 공개용 키만 들어 있습니다.
- 더 엄격하게 하고 싶다면 `scripts/gen-keystore.sh` 로 비공개 키를 만들어 코드의 키를 교체하세요(그러면 기존 앱은 지우고 다시 설치해야 합니다).

## 문제 해결

| 증상 | 해결 |
|---|---|
| 설치가 "앱이 설치되지 않음" | 이전에 다른 서명으로 설치한 앱이 있으면 지우고 다시 설치(연결 코드를 다시 받아야 해요). 이후엔 같은 키라 덮어쓰기됩니다. |
| 아들 화면이 안 바뀜 | 화면 위 주황 띠가 보이면 인터넷이 끊긴 것입니다. 연결되면 눌러 둔 동작이 자동으로 전송돼요. |
| "이 기기의 연결이 해제됐어요" | 부모 앱 설정에서 기기를 해제했거나 앱 데이터를 지웠을 때입니다. 새 연결 코드로 다시 연결하세요. |
| PIN 을 잊음 | 잠금 화면의 "PIN을 잊었어요"로 연결을 해제한 뒤, **복구 코드**를 연결 입력칸에 붙여 넣어 부모 기기로 다시 연결합니다. 복구 코드는 미리 부모 앱 설정에서 확인해 적어 두세요. |
| 빌드가 실패 | Actions 의 실행 → Annotations 에 Gradle 실패 원인이 요약됩니다. 빌드 로그는 Artifacts 의 `gradle-build-log-NN` 에 있습니다. |

## 개발

```bash
npm install
npm test               # SQL(로컬 PostgreSQL 16) + 단위 + 브라우저 E2E (Playwright/Chromium)
npm run android:sync   # www/ 를 android/ 로 복사 (CI 가 자동으로 함)
npm run check:android  # 안드로이드 셸 점검
```

- `www/` — 앱 본체(번들러 없는 ES 모듈). 서버 상태가 진실이고, 눌러 둔 동작은 순서 있는 큐로 보냅니다.
- `supabase.sql` — 서버 스키마와 함수(Supabase SQL Editor 에서 실행).
- `docs/superpowers/` — 설계 문서와 구현 계획.
